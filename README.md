# DocPilot

**Live app: https://docpilot-5ov2htcjpmznaondpjkiqg.streamlit.app**

Version-aware RAG assistant for the pandas library (1.5 vs 2.2). It answers "how do I do X in pandas?" for the version you specify and warns when the answer differs across versions.

Note: free Streamlit Community Cloud apps sleep when idle. If the app shows a "wake up" button, click it and wait a minute or two.
